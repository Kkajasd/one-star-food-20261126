One original English sentence (max 200 characters), in the voice of an alien tourist giving planet Earth a one-star review while still slipping in a real compliment about the food: a hotel that charges extra for gravity, pigeons that steal lunch, and a stranger's samosa that makes the visitor stay another week.

## Run it

```sh
node main.ts
```

The program writes the entry sentence to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`).
